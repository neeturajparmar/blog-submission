🚀 Quick GitHub Submission Steps

  1. Create a new repository on GitHub (e.g., my-webdev-blog).
  2. Upload this index.html file to your repository.
  3. Go to Repository Settings > Pages.
  4. Under Build and deployment, select the main branch and click Save.
  5. Your website will be live at: https://yourusername.github.io/my-webdev-blog!
